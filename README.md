# any-radio

PowerShell-скрипт для запуска интернет-радио в American Truck Simulator и Euro Truck Simulator 2 через VLC или FFmpeg.

**Текущая версия:** 0.1.0 (см. [CHANGELOG.md](CHANGELOG.md))

## Зачем

ATS и ETS2 не понимают часть форматов интернет-радио (AAC, Opus, FLAC и др.). Скрипт запускает VLC (или FFmpeg), который принимает поток, перегоняет его в MP3 и раздаёт локально. Игра читает готовый MP3 как обычное радио.

Прямые MP3/OGG-потоки не проксируются — они идут в игру как есть.

## Требования

- Windows
- Windows PowerShell (встроен в Windows)
- [VLC](https://www.videolan.org/vlc/) **или** [FFmpeg](https://www.gyan.dev/ffmpeg/builds/) (один из двух)
- Для FFmpeg — **full**-сборка с `libmp3lame` (essentials-сборки часто без MP3-энкодера)

## Установка

1. Архив с [Releases](https://github.com/Sonso-Baki/any-radio/releases) распаковывается в любую папку, например `C:\any-radio\`.
2. `Settings.cmd` запускается двойным кликом. В меню выбирается бэкенд (**1**), добавляются станции (**2**), затем выполняется выход (последний пункт).
3. В Steam открывается: Библиотека → правый клик по игре → Свойства → Общие → Параметры запуска.
4. В конфигураторе выбирается пункт **«Команда запуска для Steam»** — он покажет готовую строку с путём к папке с приложением. Строка копируется (клавиша `к`/`k`) и вставляется в поле «Параметры запуска».
5. Игра запускается.

**Если в системе найдена только одна игра** (ATS или ETS2), выбор игры пропускается, меню сразу открывается для неё, а пункт «Назад к выбору игры» не показывается.

## Как это работает

1. Скрипт читает `config/streams.json`, проверяет свободность портов, находит VLC/FFmpeg и игру.
2. Для каждой проксируемой станции запускается свой процесс VLC/FFmpeg, который слушает `http://127.0.0.1:<port>/radio.mp3`. Путь `/radio.mp3` задаётся переменной `$RadioPath` в `scripts\common.ps1`.
3. Скрипт запускает игру и запоминает её процесс, чтобы понять, когда она закроется.
4. Фоновая часть скрипта следит одновременно за игрой и за каждым прокси-процессом.
   - Когда игра закрывается — все прокси останавливаются, скрипт завершается.
   - Если прокси-процесс FFmpeg завершился (например, из-за паузы радио в игре) — он сразу запускается заново на том же порту. При возобновлении радио в игре поток снова играет (задержка 1–3 секунды).
5. VLC-прокси при паузе не завершается (`--sout-keep --repeat`), поэтому перезапуск не нужен.

Одновременно можно проксировать не более **63 станций**. Это ограничение Windows: каждая проксируемая станция — отдельный процесс, и система не позволяет следить более чем за 63 такими процессами сразу (ещё один слот занят самой игрой). Прямые потоки (без порта) в этот лимит не входят — для них ничего не запускается.

## Структура

- `Settings.cmd` — запуск конфигуратора
- `README.md` — эта документация
- `CHANGELOG.md` — история изменений
- `LICENSE` — лицензия (MIT)
- `.gitignore` — исключения для git
- `vlc.exe` — опционально: портативный VLC рядом со скриптами
  (ищется в `scripts\vlc.exe`); в `.gitignore`
- `config\streams.json` — бэкенд и список станций
- `config\lang.txt` — текущий язык (ru/en)
- `config\direct-mp3-cache.json` — кэш определения прямых потоков
  (создаётся автоматически)
- `config\ffmpeg-path.txt` — кэш пути к найденному FFmpeg с `libmp3lame`
  (создаётся автоматически; ускоряет поиск при входе в раздел FFmpeg)
- `config\any-radio.log` — лог (создаётся автоматически)
- `config\any-radio.log.1` … `.5` — ротированные логи (создаются при превышении 1 МБ, FIFO, до 5 слотов)
- `config\ffmpeg-error.log` — stderr FFmpeg в append-режиме
  (создаётся при ошибках)
- `config\ffmpeg-error.log.1` … `.5` — ротированные логи FFmpeg (создаются при
  превышении 1 МБ, FIFO, до 5 слотов)
- `config\ffmpeg-probe.log` — stderr FFmpeg при проверке бэкендов
  (не трогает `ffmpeg-error.log`)
- `config\streams-export.json` — экспорт станций (создаётся при экспорте)
- `config\live_streams.sii.bak1`, `.bak2`, `.bak3` — бэкапы `.sii`
  (создаются при каждой правке `.sii`, FIFO-ротация; `.bak3` — самый свежий)
- `lang\en.ps1`, `lang\ru.ps1` — английские и русские строки
- `scripts\common.ps1` — общие функции и C#-рантайм
- `scripts\settings.ps1` — конфигуратор
- `scripts\ats_radio.ps1`, `scripts\ets2_radio.ps1` — тихие раннеры
  для ATS и ETS2

## Меню конфигуратора

Пункты меню строятся динамически. Базовый набор (одинаков для одной и двух игр):

1. Сменить бэкенд (VLC / FFmpeg / Auto)
2. Добавить станцию
3. Удалить станцию
4. Список станций
5. Установить FFmpeg (winget)
6. Команда запуска для Steam
7. Сменить язык (RU/EN)
8. Импорт станций
9. Экспорт станций
10. Аудит станций (с возможностью перезаписи `live_streams.sii`)

Далее — в зависимости от количества найденных игр:

- **Две игры**: 11. Назад к выбору игры, 12. Очистить кэш и логи, 13. Выход.
- **Одна игра**: пункт «Назад к выбору игры» не показывается, поэтому 11. Очистить кэш и логи, 12. Выход.

Номера всегда совпадают с реальным порядком пунктов — меню перестраивается под ситуацию.

## Смена бэкенда (VLC / FFmpeg / Auto)

Пункт **1**. Позволяет выбрать глобальный бэкенд для всех станций:

- **VLC** — все станции через VLC. VLC не завершается при паузе радио в игре.
- **FFmpeg** — все станции через FFmpeg (нужна full-сборка с `libmp3lame`). При паузе радио в игре FFmpeg завершается, но фоновая часть скрипта автоматически перезапускает его на том же порту.
- **Auto** — per-station выбор: у каждой станции можно указать свой бэкенд (`vlc`/`ffmpeg`), иначе используется FFmpeg. Если выбранный бэкенд недоступен, скрипт пробует второй. При выборе Auto конфигуратор предложит проверить бэкенды для всех станций и сохранить рекомендации (при доступных обоих рекомендуется FFmpeg).

## Добавление станции

Пункт **2**.

1. Вводится URL. Поддерживается `http://` и `https://`:
   - если введён `https://`, скрипт спросит подтверждение: «https:// будет заменён на http://. Продолжить? (д/н)». При ответе «д» адрес заменится на `http://`, при «н» — вернёт к вводу URL;
   - локальные адреса (`127.0.0.1`, `localhost`, `0.0.0.0`, `::1`) запрещены;
   - при неполном `http://` (без хоста) — «URL неполный: укажите адрес после http://»;
   - при неполном/битом `https://` — «URL должен начинаться с http://»;
   - при ошибке скрипт переспросит URL.
2. На экране добавления выводится подсказка: «Импорт .m3u и .json через соответствующий раздел», а также сколько станций ещё можно проксировать (до 63).
3. Скрипт проверит, похож ли поток на прямой MP3/OGG, и покажет подсказку.
   - **Требует перекодировки?** — явный ответ. Если «нет», порт не назначается, станция идёт как прямой поток (прокси не запускается).
4. Если нужна перекодировка, порт подбирается автоматически из диапазона `18084–20000`.
5. Дополнительно (можно пропустить Enter'ом): жанр (пусто), язык (`RU`), битрейт (`128`), избранное (`0`).
6. Станция добавится в `config\streams.json` и в `live_streams.sii` в формате `http://127.0.0.1:<port>/radio.mp3|<Name>|<Genre>|<Lang>|<Bitrate>|<Fav>` (для прокси) или `<direct-url>|<Name>|<Genre>|<Lang>|<Bitrate>|<Fav>` (для прямого потока).

Если проксируемых станций уже 63 — добавить новую нельзя, скрипт покажет сообщение и вернёт к вводу.

## Удаление станции

Пункт **3**. Показывает список станций из конфига с индексами и портами. Можно ввести:

- один индекс — `0`;
- несколько через запятую — `1,3,5`;
- диапазон — `1-4`;
- все — `all` / `все`.

После выбора показывает имена станций к удалению и просит подтверждение. Удаляет из `config\streams.json` и из `live_streams.sii` (по URL, для прокси — `http://127.0.0.1:<port>/radio.mp3`), затем синхронизирует индексы.

## Список станций

Пункт **4**. Показывает станции из `config\streams.json` и `live_streams.sii` с портом, жанром, языком, битрейтом и избранным.

Команды:
- `з [n]` (или `g`) — редактировать станцию в конфиге (имя, прокси, URL, жанр, язык, битрейт, избранное, бэкенд).
- `к [n]` (или `k`) — скопировать внешнюю ссылку станции в буфер обмена. Копируется только исходный URL (без индекса и названия). Если URL пустой — «URL пустой», если некорректный — «URL некорректный».
- `и` (или `b`) — назад.

Пробел между буквой и числом не обязателен: `з44`, `g44`, `к0`, `k0`.

Ссылку в списке можно открыть в браузере по **Ctrl+ЛКМ** (встроенное поведение терминала Windows).

После сообщений (успешное копирование, ошибки, неверная команда) появляется «Нажмите Enter для возврата» — Enter возвращает к списку и приглашению «Ввод (и = назад)».

## Установка FFmpeg (winget)

Пункт **5**. Показывает, найден ли FFmpeg с `libmp3lame`, и куда он установлен. Если не найден — пункт «1. Установить FFmpeg (winget)». Если найден — пункт «1. Запустить winget» (проверит обновления).

Путь к найденному FFmpeg кэшируется в `config\ffmpeg-path.txt`, поэтому при повторном входе в раздел поиск не запускает FFmpeg заново.

## Команда запуска для Steam

Пункт **6**. Показывает готовую строку для поля «Параметры запуска» Steam — с путём к папке с приложением (подставляется автоматически). Строка зависит от выбранной игры (ATS или ETS2).

- `к` / `k` — скопировать команду в буфер обмена.
- `и` / `b` — назад.

Скопированная строка вставляется в Steam → Библиотека → правый клик по игре → Свойства → Общие → Параметры запуска.

## Смена языка (RU/EN)

Пункт **7**. Переключает язык интерфейса между русским и английским. Выбор сохраняется в `config\lang.txt`. При первом запуске, если файла нет, язык определяется по системному (русский для ru/uk/be/kk и др., иначе английский).

## Импорт станций

Пункт **8**. Импорт из `.m3u` / `.m3u8` / `.json`. По умолчанию предлагается `config\streams-export.json`.

- Пропускает локальные адреса, прокси-URL и дубликаты URL.
- Переназначает занятые порты.
- `https://` автоматически заменяется на `http://` (без подтверждения).
- Показывает, сколько импортировано, пропущено, пропущено прокси, пропущено локальных, пропущено дублей, переназначено портов и без порта.
- Поле `index` из JSON при импорте игнорируется — после импорта оно проставляется из `live_streams.sii`.
- При ошибке (файл не найден, пустой, нет станций) после Enter возвращает **к вводу пути** в том же экране импорта.
- При вводе `и`/`b` на запросе пути — выход в главное меню.
- Если при добавлении (не замене) проксируемых станций стало бы больше 63 — импорт отменяется с сообщением.

## Экспорт станций

Пункт **9**. Показывает объединённый список с пометками `[cfg]`, `[sii]`, `[both]`. Для станций с портом выводится `[port N]`, для прямых — без порта. Спрашивает источник: только конфиг, только `.sii`, или объединённое без дублей. При неверном выборе показывает сообщение и перерисовывает экран экспорта. Путь по умолчанию — `config\streams-export.json`.

В JSON пишутся только прямые ссылки на потоки (исходные URL). Локальные прокси-адреса (`127.0.0.1`) в JSON не попадают. Для проксируемых станций дополнительно сохраняется поле `port` — «желаемый порт», который при следующем импорте проверяется и при занятости переназначается.

Формат JSON: `{ version, backend, streams: [{ url, port, name, genre, lang, bitrate, fav, backend }] }`.

## Аудит и перезапись live_streams.sii

Пункт **10**. Сравнивает `config\streams.json` и `live_streams.sii` и показывает:
- станции только в конфиге (нет в `.sii`),
- станции только в `.sii` (нет в конфиге),
- расхождения полей (порт/URL, жанр, язык, битрейт, избранное),
- дубликаты имён,
- станции без индекса (`index = -1`), т.е. отсутствующие в `.sii`.

Перед отчётом порядок станций синхронизируется с `.sii` (поле `index` в `streams.json`).

После отчёта предлагает перезаписать `live_streams.sii` из конфига:
- **Целиком** — `.sii` становится точной копией `streams.json` (станции, которых нет в конфиге, удаляются).
- **Дополнить** — к существующим записям `.sii` добавляются станции из конфига, которых там ещё нет (по имени).

Файл пишется в UTF-8, `_nameless`-идентификатор сохраняется из текущего `.sii`. Перед записью создаётся бэкап `.bak1-3`.

Записи в `.sii` пишутся без символа `#`; шаблонные закомментированные строки не изменяются.

## Очистка кэша и логов

Пункт «Очистить кэш и логи» (номер зависит от количества игр). Показывает список файлов, которые будут удалены, и их размер:
- `config\direct-mp3-cache.json` — кэш определения прямых потоков;
- `config\ffmpeg-path.txt` — кэш пути к FFmpeg;
- `config\*.log.1` … `.5` — ротированные логи;
- `config\ffmpeg-probe.log` — лог проверки бэкендов;
- `config\any-radio.log`, `config\ffmpeg-error.log` — текущие логи (только если игра/прокси не запущены);
- `live_streams.sii.bak1`, `live_streams.sii.bak2` — старые бэкапы (свежий `.bak3` остаётся);
- `config\streams-export.json` — прошлый экспорт (если есть).

Вопрос очистки: «Удалить перечисленное? (д/н, и = назад)» — можно ответить `и`/`b` для отмены. После подтверждения удаляет и показывает, сколько файлов удалено и сколько байт освобождено.

## Логи

- `config\any-radio.log` — запуск/остановка прокси, правки `.sii`, сохранение конфига, ошибки.
- `config\ffmpeg-error.log` — stderr FFmpeg (append-режим; полезно для диагностики «тишины»).
- `config\ffmpeg-probe.log` — stderr FFmpeg при проверке бэкендов (не смешивается с `ffmpeg-error.log`).

Логи ротируются по размеру: при превышении 1 МБ текущий файл переименовывается в `*.log.N`, где N — первый свободный слот от 1 до 5. Если все 5 слотов заняты — самый старый (`.5`) удаляется, остальные сдвигаются, текущий становится `.1`.

## Бэкапы live_streams.sii

Перед каждым изменением `.sii` рядом создаются три слота бэкапа:
- `live_streams.sii.bak1` — самый старый из сохранённых
- `live_streams.sii.bak2`
- `live_streams.sii.bak3` — самый свежий

При новом изменении слоты сдвигаются (`.bak2` → `.bak1`, `.bak3` → `.bak2`, текущий → `.bak3`), так что всегда хранятся три последних состояния. Если слот занят (например, открыт в редакторе) — он пропускается, остальные копируются.

## Если что-то не так

- `VLC not found` — VLC не установлен или стоит в нестандартном месте.
- `FFmpeg not found` — FFmpeg не установлен (пункт «Установить FFmpeg» — установка через winget).
- `FFmpeg found but without libmp3lame` — установлена essentials-сборка. Требуется full-сборка с https://www.gyan.dev/ffmpeg/builds/.
- `Port X is busy` — порт занят (обычно VLC/FFmpeg от прошлого запуска). Стоит закрыть процесс или сменить порт.
- `American Truck Simulator not found` / `Euro Truck Simulator 2 not found` — игра не найдена в Steam-библиотеках.
- `config/streams.json is corrupted` — файл конфига битый. Восстанови из резервной копии или удали (создастся дефолт).
- `common.ps1 not found` — требуется распаковать архив заново.
- Радио пропало в игре, но `live_streams.sii` выглядит нормально — стоит проверить, что файл сохранён в UTF-8 (Notepad++ → Кодировки → UTF-8).
- Тишина в режиме FFmpeg — проверяется `config\ffmpeg-error.log`. Частая причина: нет `libmp3lame` (нужна full-сборка).
- «Игра уже запущена» — игру требуется закрыть перед запуском прокси/добавлением/удалением станции.
- FFmpeg-станция не восстановилась после паузы за 3 секунды — проверяются `config\any-radio.log` и `config\ffmpeg-error.log`; возможно, порт занят другим процессом, и перезапуск не удался.
- В разделе «Список станций» при копировании ссылки появилось «URL пустой» или «URL некорректный» — у станции нет URL или он записан неверно (должен начинаться с `http://` и не быть локальным адресом).
- «Прокси-станций не может быть больше 63» — достигнут лимит одновременных прокси. Лишние станции удаляются или переводятся в прямые.

## Обновление

Новый архив распаковывается **поверх** старой папки. `config\streams.json` не перезапишется (его нет в архиве).
