### Added

- Запуск интернет-радио в American Truck Simulator и Euro Truck Simulator 2
  через VLC или FFmpeg: поток принимается локально, перекодируется в MP3
  и раздаётся на `http://127.0.0.1:<port>/radio.mp3`.
- Прямые MP3/OGG-потоки не проксируются — идут в игру как есть.
- Бэкенды: `vlc`, `ffmpeg`, `auto` (per-station выбор). При `auto` и недоступном
  выбранном бэкенде — фолбэк на второй (VLC ↔ FFmpeg).
- В режиме `auto` при доступных обоих бэкендах рекомендуется FFmpeg
  (как более лёгкий и всеядный по форматам).
- Автопоиск VLC и FFmpeg (PATH, Program Files, winget, chocolatey, scoop,
  `%LOCALAPPDATA%`).
- Проверка `libmp3lame` (`Find-FFmpegFull`, `Test-FFmpegEncoders`).
- Кэш пути к найденному FFmpeg (`config\ffmpeg-path.txt`) — ускоряет повторный
  вход в раздел «Установить FFmpeg».
- Автопоиск игры через реестр Steam и `libraryfolders.vdf`.
- Конфигуратор с динамическим меню (пункты строятся в зависимости от количества
  найденных игр).
- Добавление станции: проверка URL (`http://`, замена `https://` с подтверждением,
  запрет локальных адресов), явный ответ на вопрос о перекодировке,
  автоподбор порта `18084–20000`.
- Редактирование станции в конфиге (имя, прокси, URL, жанр, язык, битрейт,
  избранное, бэкенд).
- Удаление станций (несколько через запятую, диапазон, все).
- Список станций с командами `з [n]`/`g [n]` (редактировать станцию в конфиге),
  `к [n]`/`k [n]` (скопировать внешнюю ссылку), поиск по имени.
  Обе буквы (кириллица и латиница) работают в любом языке интерфейса;
  в подсказках выводится только соответствующая текущему языку.
- После сообщений в списке станций (копирование, ошибки, неверная команда) —
  «Нажмите Enter для возврата».
- Пункт меню «Команда запуска для Steam»: показывает готовую строку
  для параметров запуска Steam с путём к текущей папке (зависит от игры),
  копирование в буфер по `к`/`k`.
- Импорт станций из `.m3u` / `.m3u8` / `.json`; пропуск локальных адресов,
  прокси-URL и дубликатов URL; переназначение занятых портов;
  автоматическая замена `https://` на `http://`.
- Экспорт станций (только конфиг / только прямые из `.sii` / объединённое без дублей).
- Аудит расхождений `streams.json` ↔ `live_streams.sii` с возможностью
  перезаписи `.sii` («Целиком» / «Дополнить»).
- Автоматическое добавление/удаление/обновление станций в `live_streams.sii`
  (точечная правка, с бэкапом `.bak1`–`.bak3`, FIFO-ротация).
- `Rewrite-Sii` сохраняет `_nameless`-идентификатор из текущего `.sii`
  и пишет корректную структуру (`SiiNunit` + `live_stream_def` + две `}`).
- `Sync-IndexFromSii` — синхронизация порядка станций: поле `index`
  в `streams.json` проставляется по индексам из `live_streams.sii`.
- C#-рантайм `ProxyRuntime`: запуск прокси, ожидание выхода из игры
  и надзор за процессами FFmpeg без циклов и polling в PowerShell.
- Авто-перезапуск FFmpeg-прокси при завершении процесса (например, после паузы
  радио в игре) через `WaitForMultipleObjects`.
- `Write-Utf8NoBom` — все файлы (`.sii`, `streams.json`,
  `direct-mp3-cache.json`, `streams-export.json`) пишутся в UTF-8 **без BOM**.
- Кэш определения прямых потоков (`direct-mp3-cache.json`, TTL 7 дней).
- Очистка кэша и логов с показом списка файлов и размера, опциональным
  сохранением текущих логов, если игра/прокси запущены.
- Логи `any-radio.log` / `ffmpeg-error.log` с ротацией по 1 МБ (до 5 слотов,
  FIFO). Лог проверки бэкендов — отдельный `ffmpeg-probe.log`.
- Смена языка RU/EN; автоопределение системного языка; проверка паритета ключей
  между `ru.ps1` и `en.ps1`.
- Установка FFmpeg через winget.
- Запуск игры через `ShellExecuteEx` с передачей `hProcess` в C#-рантайм.
- Ограничение: одновременно проксируется не более 63 станций
  (ограничение `WaitForMultipleObjects`; один handle занят игрой).
  Прямые потоки в лимит не входят. При добавлении/импорте, если лимит
  превышается, операция отменяется с сообщением.

### Notes

- Требуется Windows PowerShell (встроен в Windows).
- Для FFmpeg — **full**-сборка с `libmp3lame` (essentials-сборки часто без
  MP3-энкодера).
- VLC-прокси при паузе не завершается (`--sout-keep --repeat`), поэтому
  перезапуск не нужен. FFmpeg-прокси завершается, но C#-рантайм поднимает его
  заново на том же порту (задержка воспроизведения 1–3 секунды).
- Записи в `.sii` пишутся без символа `#`; шаблонные закомментированные строки
  не изменяются.
